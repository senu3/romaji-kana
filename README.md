# Romaji Kana

Romaji Kana は、ローマ字で書いた文章を日本語に変換しながら編集できるMarkdownエディターです。

<img width="1018" height="645" alt="image" src="https://github.com/user-attachments/assets/cd6dad7a-579a-40dc-9b3f-965f428ced67" />

- リアルタイムで変換候補を出し、LLMが文脈に応じて候補を修正します
- 入力を止めたときや句読点を打ったとき、候補を自動で確定できます。
- 個人語彙の登録や文書内単語の抽出で、頻出語彙を入力しやすくできます。

## ダウンロード先

https://github.com/senu3/romaji-kana/releases/tag/V0.0.2
ZIPファイルを解凍し、`romaji-kana.exe` を起動してください

## はじめる

1. 初期設定モーダルで利用するプロパイダー（OllamaかLMStudio）を選択します
   （プロパイダー設定をスキップしても動作します）
2. エディターに `honwoyomu` と入力し、続けて `.` を打ちます。

ローマ字が「本を読む。」のような日本語へ変われば完了です。
手動確定に変えたいときは右側の設定パネルを開いてください。

操作説明は [ユーザーガイド](USERGUIDE.md) を参照してください。
