# Romaji Kana

Romaji Kana は、ローマ字で書いた文章を日本語に変換しながら編集できるMarkdownエディターです。

- 入力を止めたときや句読点を打ったときに変換し、必要に応じて候補を確認できます。
- 個人語彙の登録、文書内語彙の抽出で、よく使う言葉を入力しやすくできます。


## はじめる

1. 初期設定モーダルで利用するプロパイダー（OllamaかLMStudioを選択します）
2. エディターに `honwoyomu` と入力し、続けて `.` を打ちます。

ローマ字が「本を読む。」のような日本語へ変われば完了です。手動で確定したいときは右側の設定パネルを開いてください。

操作説明は [ユーザーガイド](USERGUIDE.md) を参照してください。
