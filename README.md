# Romaji Kana

Romaji Kana は、ラフなローマ字入力を自然な日本語へ変換するローカルファーストの
Markdown エディタです。

## 必要なもの

- Ollama または LM Studio
- 日本語変換に使えるローカルモデル

## はじめに

アプリはすぐに編集画面で開き、モデルの接続中や未接続でも入力と下書き保存はできます。
上部のモデル表示を押すと、モデルプロバイダ（Ollama / LM Studio）、接続先、モデルを設定できます。
モデルプロバイダに応じて、利用可能なモデル一覧が自動で取得されます。

デフォルトでは Ollama の API URL `http://localhost:11434` の `gemma3` を使います。LM Studio の
デフォルト URL は `http://localhost:1234` です。

gemma4、Qwen3.5 の 9B 以上を推奨します。Thinkingモードはオフが推奨です。

## 入力例

### Romajiを変換する

短い文や段落を書きながら、その場で変換したいときの基本操作です。
手動ショートカットの初期値は、Windows/Linux では `Ctrl+Enter`、macOS では
Cmd+Enter になります。

```text
kyouha kaigi no youten wo kakunin shimasu.
```

`.` を入力すると、直前の文が変換されます。

```text
今日は会議の要点を確認します。
```

既存の行の一部だけを変換したい場合は、変換したい範囲を選択して手動ショートカットを
実行します。選択範囲があるときは、行全体ではなく選択した範囲だけが変換されます。

変換はキューで順番に処理されます。変換中に次のトリガーが発火しても、並列実行せず
入力順に処理されます。

## 変換結果の適用方法

変換結果の適用方法は 2 種類あります。設定パネルで切り替えられます。

- 直接置換: 元のローマ字を変換後の日本語ですぐに置き換えます。
- 候補を表示: 変換候補をインライン表示します。`Tab` で採用し、`Esc` で破棄します。
  `Ctrl/Cmd+/` で別候補を再生成できます。

Undo すると、変換後の文章を元のローマ字へ戻せます。Undo/Redo 操作をきっかけに変換が
再実行されることはありません。

`Ctrl/Cmd+F` またはツールバーの検索ボタンで、検索と置換を開けます。ステータスバーには
現在の行・列と文字数（選択中は選択文字数）が表示されます。

ツールバーの「自動変換」をオフにすると、`.`、`,`、Enter による変換だけを停止できます。
`Ctrl/Cmd+Enter` の手動変換は引き続き利用できます。

## 履歴

履歴パネルでは、この起動中に確定・適用した変換を最大100件確認できます。項目にマウスを
重ねると、現在のエディタ上の対応範囲にプレビューを表示します。

「再試行」は同じ入力をもう一度変換します。「別候補」は前回と同じ出力を避けるように
モデルへ指示します。履歴から再実行した場合は、現在の対象範囲に残っている固定語も再保護します。

## 入力補完

変換スタイルパネルでは、入力にない文字をAIがどこまで補うかを選べます。

- なし: 現在の読みを変えず、そのまま変換します。`ariga` は `ありが` になります。
- 単語: 途中で切れた最後の単語だけを補います。`ariga` は `ありがとう` の候補になります。
- 文章: 入力済みの内容を保ちながら、助詞や文末を最小限補います。

入力補完が実際に発生した場合は、設定が「直接置換」でも候補として表示されます。`Tab` で
確定し、`Esc` で破棄できます。初期値は「なし」で、従来の忠実な変換動作を維持します。

## 文体プリセット

変換スタイルパネルで変換の文体を選べます。

- 指定なし: 文体を強く寄せず、中立的に変換します。
- 会話: 話し言葉として自然な表現を優先します。
- ビジネスメール: メール文として自然な敬体・業務表現を優先します。

より細かく制御したい場合は、同じパネルの詳細設定からプロンプトを編集できます。

## ユーザー辞書

エディタ上部のファイルバー右側にある辞書ボタンから開きます。人名、サービス名、製品名、
略語など、毎回安定して変換したい語を登録できます。

辞書項目には以下を設定します。

- Reading: マッチさせるローマ字読み。
- Output: 挿入したい固定の出力。
- Note: 補足メモ。
- Enabled: 項目を有効にするかどうか。

たとえば `openai` を `OpenAI`、`api` を `API` として登録できます。辞書にマッチした部分は
LLM に送る前に分離され、登録した出力として扱われます。

## バッククォート指定

一時的な未知語や英単語は、バッククォートで囲むとその部分を固定できます。囲った文字列は
そのまま残り、バッククォートだけが外れます。前後のローマ字は通常どおり変換されます。

例:

```text
`openair` ni iku.
```

変換例:

```text
openairに行く。
```

一時的な語はバッククォート、繰り返し使う語はユーザー辞書に登録する使い分けが基本です。

## 漢字混在入力

ローマ字の中に漢字を含めると、その漢字語は固定語として扱われます。

```text
watasiha迎賓館niikoutoomoimasu.
```

変換例:

```text
私は迎賓館に行こうと思います。
```

漢字を含む語は LLM に送る前に分離され、前後のローマ字だけが変換されます。

## 設定

設定パネルでは以下を調整できます。

- モデルプロバイダー、API URL、モデル、Thinkingモード
- 直接置換 / 候補表示の切り替え
- 自動変換とトリガー
- 手動ショートカット
- 句読点変換

新規下書きだけでなく、ファイルを開いている途中の未保存内容もローカルに退避され、次回起動時に
復元されます。明示的に保存すると元の Markdown ファイルへ書き込まれます。

## 開発

Tauri v2、React、TypeScript、CodeMirror 6 で構成されています。開発時は Node.js と npm が必要です。

```bash
npm install
npm run dev
```

デスクトップシェルで起動する場合:

```bash
npm run tauri dev
```

## 検証

```bash
npm test
npm run build
```
