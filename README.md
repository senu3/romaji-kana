# Romaji Kana

Romaji Kana は、ローマ字の下書きをローカル LLM で読みやすい日本語へ変換できる
Markdown エディターです。

- 句読点またはキーボードショートカットで、書いている箇所をそのまま日本語へ変換できます。
- 変換候補、文体、入力補完、文書語彙、ユーザー辞書を使って結果を調整できます。
- Markdown ファイルを編集・保存し、未保存の下書きも次回起動時に復元できます。
- 同じ Wi-Fi のスマホから PC の文書を編集し、PC 上のローカルモデルで変換できます。

## はじめる

ここでは、Tauri デスクトップアプリと Ollama の既定 URL
`http://localhost:11434` を使います。先に次のものを用意してください。

- Node.js と npm
- 各 OS で Tauri v2 を実行できる開発環境
- Ollama と、日本語変換に使うローカルモデル

### アプリを起動する

1. 依存パッケージをインストールします。

   ```bash
   npm install
   ```

2. Ollama を起動し、使用するモデルを利用可能な状態にします。
3. デスクトップアプリを起動します。

   ```bash
   npm run tauri dev
   ```

### 最初の文章を変換する

この手順では、初期設定の **直接置換** と、ピリオドによる **自動変換** を使います。

1. 画面右上のモデル表示を選択します。
2. **Ollama** を選択します。
3. **モデル** から Ollama で利用できるモデルを選択します。
4. **接続チェック** を選択します。接続メッセージに選択したモデルが表示されます。
5. **完了** を選択します。
6. エディターに次の文を入力します。

   ```text
   kyouha kaigi no youten wo kakunin shimasu
   ```

7. 続けて `.` を入力します。ローマ字部分が日本語へ置き換われば完了です。

変換方法、候補の確認、辞書、文書の保存、設定の既定値については
[USERGUIDE.md](USERGUIDE.md) を参照してください。

### スマホからPC版を使う

PC版を起動したまま、右端の **スマホ** を選択して **スマホ連携を開始** を選びます。
表示された URL と6桁の接続コードを使うと、同じ Wi-Fi のスマホから文書を編集・変換できます。
詳しい手順と注意事項は
[USERGUIDE.md の「スマホからPC版を使う」](USERGUIDE.md#スマホからpc版を使う)
を参照してください。

## 起動時に困ったとき

- モデル表示が **未接続** または **要確認** の場合は、Ollama が起動していること、API URL、
  選択したモデルを確認してから **接続チェック** を実行してください。
- `npm run dev` で開くブラウザー版では、変換と下書き編集はできますが、ファイルの
  **開く** と **保存** は利用できません。ファイルを扱う場合は `npm run tauri dev` を使ってください。

詳しい対処方法は [USERGUIDE.md の「問題を解決する」](USERGUIDE.md#問題を解決する)
にあります。不具合は [GitHub Issues](https://github.com/senu3/romaji-kana/issues) へ報告できます。

## 開発

ブラウザーで UI を開発する場合:

```bash
npm run dev
```

テストとビルド:

```bash
npm test
npm run test:e2e
npm run build
```

デスクトップアプリの配布用ビルド:

```bash
npm run tauri build
```
